# HyperTech PWA Wrapper

Installable Chrome PWA shell for the existing HyperTech Streamlit system.

- Installed name: HyperTech
- Icon: HyperTech logo
- Display: standalone
- Existing Streamlit + Supabase system remains unchanged
- No Supabase keys or passwords are stored here

The shell embeds the live public Streamlit app using Streamlit's supported `?embed=true` mode.
